# Job Scraper (Python)

A simple Python project that scrapes remote developer jobs and filters them based on user input.

## Features
- Scrapes job listings from RemoteOK
- Filters jobs by keyword
- Displays results in terminal
- Saves results to CSV file

## Tech Stack
- Python
- Requests
- BeautifulSoup

## How to Run

1. Install dependencies:
pip install -r requirements.txt


2. Run the script:

python main.py


3. Enter a keyword:

python


## Output
- Prints matching jobs
- Saves them in `jobs.csv`
